Bulk Download Options (released on trial basis)
For novice users:
Advantages: Browser based download, doesn't require any other installations.
Disadvantages: (1) Directory structure is not available for the downloaded files.
(2) Browser compatibility/convenience has to be verified/configured with a
few downloads first.

Script based:
Advantages: Directory structure is preserved for the downloaded files.
Disadvantages: (1) New script is required to be downloaded for every login
and shall work only until a browser session is active.
(2) Requires a basic know-how to run a script.
(3) May need translation to batch script for windows users.
